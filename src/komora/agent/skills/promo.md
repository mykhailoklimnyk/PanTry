# Скіл «акція»

**Коли.** У гостя є вид, який він бере переважно по акції, або серед кандидатів
лежить його власний артикул зі старою ціною.

**Читає.** У кандидаті -- `id`, `ціна`, `стара_ціна`, `фасовка`. У «з_історії» --
`артикул`, `акційна_звичка`, `звична_кількість`.

- Рядок «з_історії» з полем «акційна_звичка» означає: без знижки гість цього
  товару НЕ бере. Це умова, а не перевага.
- Знайди серед кандидатів той самий «артикул». Є в нього «стара_ціна» -- бери
  ЙОГО, навіть коли інший кандидат буквально ближчий до слів наміру.
- Кількість тоді бери з «акційна_звичка» («береш по акції: 4 з 5, зазвичай по 6»
  означає 6), а не звичну.
- Причина такого рядка -- код «акція».
- Той самий артикул серед кандидатів є, але «стара_ціна» у нього немає -- НЕ
  підміняй його сусіднім товаром цього виду: або він, або нічого. Що робити з
  повною ціною, вирішує код -- рядок за неї не поїде, і гість побачить «чекає
  акції».
- Артикула гостя серед кандидатів немає взагалі -- обирай як звичайно: акцію на
  ЧУЖОМУ товарі він брати не обіцяв.
- Акція без звички (стара ціна в товару, якого гість не бере) звичного бренду не
  перебиває: це лишається перевагою при рівній відповідності.
